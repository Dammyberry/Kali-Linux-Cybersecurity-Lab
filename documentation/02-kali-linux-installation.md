# Kali Linux Installation

## 1. Objective

The objective of this stage was to install Kali Linux as the guest operating system inside Oracle VirtualBox.

Kali Linux is a Linux distribution designed for cybersecurity, penetration testing, digital forensics, and security assessment.

## 2. Tools Used

- Oracle VirtualBox
- Kali Linux ISO installation image
- Windows 11 host operating system

## 3. Procedure

1. Downloaded the Kali Linux installation image from the official Kali Linux website.
2. Opened Oracle VirtualBox.
3. Selected the option to create a new virtual machine.
4. Named the virtual machine Kali Linux.
5. Selected the appropriate Linux operating system type and version.
6. Allocated memory and virtual processor resources.
7. Created a virtual hard disk for the installation.
8. Attached the Kali Linux ISO image to the virtual machine.
9. Started the virtual machine and followed the Kali Linux installation wizard.
10. Completed the installation and restarted the virtual machine.

## 4. Verification

After installation, the Kali Linux virtual machine was started to confirm that the operating system loaded successfully.

## 5. Outcome

Kali Linux was installed as a guest operating system inside Oracle VirtualBox and became the primary environment for cybersecurity lab exercises.

## 6. Security and Learning Notes

Running Kali Linux in a virtual machine provides a controlled environment for learning Linux administration and cybersecurity tools without replacing the host operating system.
