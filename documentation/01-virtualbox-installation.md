# VirtualBox Installation

## 1. Objective

The objective of this stage was to install Oracle VirtualBox on a Windows 11 host computer. VirtualBox provides the virtualization environment required to create and run a Kali Linux virtual machine.

## 2. Tools Used

- Host operating system: Windows 11
- Virtualization software: Oracle VirtualBox

## 3. Procedure

1. Visited the official Oracle VirtualBox website.
2. Downloaded the VirtualBox installer for Windows.
3. Located and opened the downloaded installer.
4. Followed the installation wizard.
5. Completed the installation using the available default settings.
6. Opened VirtualBox to confirm that the application was installed.

## 4. Verification

VirtualBox was opened after installation to confirm that the application was available and ready for virtual machine creation.

## 5. Outcome

Oracle VirtualBox was installed successfully and provided the virtualization platform for the Kali Linux cybersecurity lab.

## 6. Security and Learning Notes

Virtualization allows an isolated environment to be created for cybersecurity training. It helps separate lab activities from the host operating system and makes it easier to manage virtual machines.
