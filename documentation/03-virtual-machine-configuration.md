# Kali Linux Virtual Machine Configuration

## 1. Objective

The objective was to configure the virtual machine resources required to run Kali Linux reliably inside Oracle VirtualBox.

## 2. Configuration Areas

The following resources were configured:

- RAM allocation
- Virtual CPU allocation
- Virtual hard disk
- Operating system type
- Network adapter

## 3. Procedure

1. Opened Oracle VirtualBox.
2. Selected the Kali Linux virtual machine.
3. Opened the virtual machine settings.
4. Reviewed the system settings and memory allocation.
5. Reviewed the processor allocation.
6. Checked the virtual hard disk configuration.
7. Opened the network settings.
8. Confirmed the network adapter configuration.

## 4. Verification

The virtual machine settings were reviewed to confirm that the required resources and network adapter were configured.

## 5. Outcome

The Kali Linux virtual machine was configured to provide the computing environment needed for the cybersecurity lab.

## 6. Learning Notes

Virtual machine resources should be allocated according to the host computer's available hardware. Allocating excessive RAM or CPU resources to a guest can affect the performance of the host operating system.
